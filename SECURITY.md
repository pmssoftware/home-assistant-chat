# Security policy

Home Assistant Chat is experimental and unaudited. Only the latest released
version is supported while the project is in this testing phase.

Please report suspected vulnerabilities privately through [GitHub Security
Advisories](https://github.com/pmssoftware/home-assistant-chat/security/advisories/new).
Include the affected version, a minimal reproduction, and the impact when it
is safe to do so. Please do not disclose an unpatched vulnerability publicly.
