# Bundled QR dependencies

QR generation and scanning run locally without a CDN or runtime network call.

- `qrcode-generator` 1.4.4 generates SVG contact codes.
- `qr-scanner` 1.4.2 decodes camera frames and uploaded images.

The adapter is `qr-adapter.js`; pinned upstream files and licenses are stored in
`vendor/`. See the repository's `THIRD_PARTY_NOTICES` for attribution.
